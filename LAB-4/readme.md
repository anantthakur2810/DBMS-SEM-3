Design and operate a Social Media Database (Users, Posts, Comments, Likes) entirely using MongoDB document-model concepts. No relational/SQL tables are to be used anywhere in this lab. Fixed collections to be created in Q1 (use exactly these four): users { id, name, email, joinedDate }; posts { id, userId, content, createdAt, likeCount }; comments { id, postId, userId, commentText, createdAt }; likes { id, postId, userId, likedAt }. The structure created in Q1 is mandatory and must be reused unchanged through Q2–Q7.
