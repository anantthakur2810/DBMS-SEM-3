Build and progressively query a College Record Management database using Student, Faculty, Course and Exam as the core tables. The schema and data created in Q1 and Q2 are mandatory prerequisites for Q3–Q7 — all later queries must run against the same tables, with no new tables introduced later. Fixed schema to be created in Q1 (use exactly these four tables, columns of your choice, minimum fields shown): Student (StudentID, Name, Branch, Year); Faculty (FacultyID, Name, Department); Course (CourseID, CourseName, FacultyID, Credits); Exam (ExamID, StudentID, CourseID, Marks).
